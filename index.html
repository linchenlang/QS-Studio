ABOUT

关于 QS Studio

QS Studio 由创始人兼 CEO 林晨朗（Jason Michael） 于 2026 年发起， 是一个以技术价值为唯一尺度的独立开发者组织，用作品说话，以规范运作。

不设边界

不限定方向与领域。桌面端、Web、嵌入式、自动化、数据服务 —— 凡有技术价值与实现价值的项目，均在工作室视野之内。

规范运作

拥有完整发文体系与项目开发流程，所有对外发布内容均带有正式文件编号与署名，以组织而非个人的方式运作。

自愿无偿

工作室不以营利为宗旨，不产生商业收入，不向成员支付报酬。所有成员参与均为自愿、无偿行为。

完全开源

核心项目均以 Apache 2.0、MIT 等开源协议发布，代码公开可查，欢迎 Issue 与 Pull Request。

学习交流

项目及作品现阶段仅供学习交流与技术展示，不涉及商业用途，面向所有技术爱好者开放。

质量优先

不追求规模扩张，以项目质量、系统稳定性与可用性为底线，接受真实用户反馈并持续迭代。

FLAGSHIP

核心项目 · TADS

列车数据与查询服务系统 —— 工作室目前最完整、最成熟的开源项目。

TRAIN DATA & QUERY SERVICE

为每一次列车查询而生

TADS 是一套列车运行数据查询与管理平台，由服务端（TADS-Server）与 Web 端（TADS-Web）两部分组成， 覆盖实时正晚点、车站大屏、车厢图、站点时刻表、站到站查询等核心场景，已完全开源。

TADS-SERVER · 服务端

  • 车次查询：复车次、路局、车型、配属、担当
  • 正晚点实时追踪与车站大屏（出发 / 到达）
  • 车厢图展示、站点时刻表、站到站区间查询
  • 数据管理与还原点备份，操作日志多格式导出
  • PN532 NFC 物理密钥认证，四级权限体系
  • CPU 指令集自动降级，兼容 Windows 7 / 10 / 11

TADS-WEB · WEB 查询端

  • 纯前端应用，直接调用公开 API，无需本地服务器
  • GitHub Pages 部署，扫码即可访问
  • 手机端完整适配，随时随地查询
  • 车次查询：正晚点、车厢图、检票口 / 站台 / 出站口
  • 车站查询、站到站查询、车站大屏双模式
  • 与 TADS-Server 共享数据源，亦可独立使用
技术栈 Python / Flask / Tkinter 开源协议 Apache License 2.0
